# Eastokyo — Genki2 Language System

Eastokyo is being rebuilt as a mobile-first Japanese-learning experience for English speakers.

**Meet Genki2. Learn Japanese from a robot that feels alive.**

## Current prototype

- Mobile-first responsive homepage
- CSS-built Genki2 placeholder robot
- Mood states: sleeping, curious, proud, angry
- Interactive first-lesson demo
- Free browser speech synthesis toggle
- Local progress persistence
- Reduced-motion support

This branch intentionally avoids paid services, frameworks, and backend dependencies.
